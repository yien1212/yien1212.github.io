# 我們的小屋

靜態頁，GitHub Pages 直接提供。沒有後端，所以密鑰不能放在倉庫裡。

## 檔案
- `index.html` 只放結構
- `css/app.css` 樣式
- `js/config.js` Firebase 公開設定與暗語雜湊
- `js/guard.js` 錯誤回報、圖片與畫布自動降級
- `js/app.js` 功能

## 登入
暗語只比對 SHA-256，不明文。資料庫鑰匙由本人輸入，只放在這個分頁的 sessionStorage，重新整理後要再填一次。

## 錯誤
右下角紅點是錯誤計數。圖片壞了會換成愛心占位，畫布不可用會略過，單一功能拋錯不會關掉整頁。
